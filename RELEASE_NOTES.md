# BYAKUGAN v0.8.0-beta.130

## What's updated

- The update window now shows readable, version-specific patch notes instead of raw GitHub HTML.
- Every beta release now publishes this curated summary directly to BYAKUGAN's in-app updater.
- Older HTML or Markdown release descriptions are safely converted to clean plain text before display.
- Release validation accepts standard Windows or Unix line endings while still blocking stale or empty notes.
