# BYAKUGAN v0.8.0-beta.145

## What's updated

- Removes the HenrikDev key, history-check, and import controls from Settings. Previously saved match records remain available.
- Adds Played before indicators for public players on either team during an active match, with separate teammate and opponent counts.
- Opens saved shared matches from a player's live roster row. Each match shows its date, map, mode, result, score, agents, and both players' K/D/A.
- Keeps shared-match history across Acts and restarts, including collected non-Competitive matches. Older games without saved roster data may be missing; hidden identities remain private.
- Sends shared history to the streaming PC through the existing connection. Update both PCs to beta.145 for the new profile view.
- Adds an optional import of your own Tracker Competitive Act summary in Settings. Imported totals are shown separately and do not replace collected matches or update automatically.
- Checks Windows executable completeness before publishing the installer.
- Updates the existing BYAKUGAN installation through the normal beta updater, preserving its settings, caches, and dual-PC configuration.
